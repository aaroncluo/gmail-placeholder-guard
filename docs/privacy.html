Privacy Policy — Free Placeholder Guard for Gmail

Effective date: October 15, 2026

Free Placeholder Guard for Gmail (“the extension”) is a browser extension that warns you before you send a Gmail message that still contains square-bracket placeholders such as [Name]. This policy explains exactly what the extension does with your data. It is written to match the extension's source code, which is open and included in every release.

What the extension accesses

The extension runs only on pages under https://mail.google.com/. At the moment you trigger a send (clicking Send, pressing Enter/Space on the Send button, or pressing Ctrl/Cmd+Enter), it reads, from the Gmail page in your browser:

  • the subject line of the draft being sent, and
  • the body text of the draft being sent (excluding quoted earlier messages and your signature).

It scans that text for the characters [ and ]. If any are found, it cancels the send and shows a warning that quotes the short piece of your draft containing the brackets, so you can see what it found.

This is personal communications data. The extension does read it — that is its purpose — but only inside the page, only at the moment of sending, and only for the draft you are sending.

What the extension does not do

Collect or storeNothing is saved. There is no database, no browser storage, no cookies, no settings. Once the warning is dismissed (or the send goes through), the text that was read is discarded.
TransmitNothing leaves your browser. The extension makes no network requests of any kind and has no server. It declares no Chrome permissions beyond running on mail.google.com.
Read other mailIt does not read your inbox, other drafts, contacts, attachments, recipients, or messages you are not currently sending.
TrackNo analytics, telemetry, identifiers, or crash reporting. The only diagnostic output is one line in the browser's developer console that says the extension loaded; it contains no message content.
Sell or shareNo data is sold, shared, or transferred to anyone, for any purpose.
Use AI or remote codeBracket detection is a local text check. No AI service is involved and no code is loaded from the internet.

Permissions

The extension requests no Chrome API permissions (no storage, tabs, identity, etc.). Its only access is a content script that Chrome runs on https://mail.google.com/*, which is required to inspect the draft and show the warning inside Gmail.

Limited Use disclosure

The extension's use of information received from Google services adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used solely to provide the user-facing feature described above.

Children

The extension is not directed at children and collects no data from anyone.

Changes

If a future version changes how data is handled, this policy and the extension's version history will be updated before that version is published.

Contact
